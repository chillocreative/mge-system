## 1. Introduction & Project Scope

Chillo Creative is pleased to submit this quotation for the development of a **cross-platform mobile
application (iOS & Android)** built with the **Flutter** framework, serving as a companion to the
existing **MGE-PMS** project management system.

The mobile app will connect directly to the existing Laravel (API) backend, enabling field staff and
management to access core functions on the go — including **on-site attendance check-in with GPS &
photo**, and real-time push notifications.

**Version 1 (v1) Modules:**
1. **Login & Security** — secure authentication (Sanctum token), encrypted credential storage,
   automatic session handling.
2. **Dashboard** — role-based statistics display (Admin, Finance, Projects, Employee).
3. **Notifications** — real-time push notifications (Firebase Cloud Messaging) + in-app notifications.
4. **Projects** — project list & details, milestones, site logs, document viewing.
5. **Tasks** — task list & details, comments, attachment uploads.
6. **Attendance** — on-site check-in/out with GPS location tagging, photo proof, and an offline
   queue for areas with no connectivity.

> *The Safety, Environmental, Chat, Email, Finance and Payroll modules are NOT included in v1 and can
> be added as future phases.*
